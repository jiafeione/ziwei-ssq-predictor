# 联网开奖结果与开奖日核验协议

## 来源优先级

1. 中国福彩网：https://www.cwl.gov.cn/
2. 广东福彩：http://www.gdfc.org.cn/play_list_game_5.html
3. 四川福彩：https://www.scflcp.com.cn/ssq
4. 中彩网：https://www.zhcw.com/kjxx/ssq/
5. 网易彩票：https://sports.163.com/caipiao/lottery/ssq/{issue}

优先使用官方或官方体系来源；若页面动态加载，允许用网页浏览器读取。网易页面可作为独立辅助核验，但不能单独支撑“官方已核验”结论。

## 核验字段

两条独立来源必须一致：`issue`、`draw_date`、6个升序红球、1个蓝球。出球顺序只用于读页面，不写入 V3 状态。预测文章、开机号、专家推荐、冷热分析、奖池金额不进入计算。

## 节假日与下一期开奖日

- 不要假设每期固定间隔2或3天。
- 查询福彩官方公告、官方页面或至少两个可靠开奖日历，确认休市和顺延。
- 例如国庆期间，2026-10-01至2026-10-04休市时，2026113后下一期为2026114、开奖日为2026-10-06；日期改变后必须重新从冻结日历查日柱与纳音。
- 下一期跨年时停止自动推断，要求用户确认新年度期号。

## 失败策略

- 单一来源、页面只显示预测、号码不完整、期号/日期矛盾：输出 `pending_verification`，不推进状态。
- 两来源号码不一致：保留原状态，报告冲突 URL 和字段，不自行投票或猜测。
- 查询到结果后才可写 `source_verified_public_web`；用户直接提供的号码必须标记 `user_attested_not_source_verified`。
