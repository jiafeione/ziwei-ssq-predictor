# 可复现摘要

## V1 基准组

输入只有目标日 `draw_date`、冻结日历的 `day_pillar`、`nayin_element` 和冻结配置。`issue` 只做审计，不进入 V1 哈希。按配置中的天干、地支、纳音、四化和五行映射计算元素分，再用 SHA-256 决胜。基准组不读取历史开奖。

## V3 修正组

目标期前连续9期，从最近到最早。每期包含 `position`、`issue`、`draw_date`、`ziwei_input`、`baseline_prediction`、`actual`、`verified=true`。残差规则为：实际有而基准无加权，基准有而实际无减权，命中为0；蓝球同理。最终分为 `6*ZiweiBase + Residual`，红球全域排序取6，蓝球全域排序取1。

## 绝对校验

- 期号连续递减，窗口恰好9条。
- 红球候选评估33个，蓝球候选评估16个。
- 权重固定 `[9,8,7,6,5,4,3,2,1]`。
- 配置、日历、状态摘要任何不一致都停止。
- 同一配置、日历、完整状态和目标日期必须输出相同 JSON 核心结果。
